네이버 블로그 복붙용 — 사용법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

각 파일은 4개 구역으로 나뉘어 있습니다.

  ① 제목    → 네이버 제목란에 붙여넣기
  ② 본문    → 네이버 본문에 붙여넣기 (선 아래부터 끝까지)
  ③ 태그    → 태그창에 하나씩 입력
  ④ 이미지  → 캡처 넣을 위치 안내 (붙여넣지 마세요)

※ ①②③만 붙여넣으면 됩니다. 구분선(━━━)과 ④는 복사하지 마세요.

발행 순서 (중요)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

네이버 검색 데이터 기준으로 순서를 잡았습니다.

  1순위  3편 업종코드 차이     ← 가장 먼저!
  2순위  4편 10차→11차 변환
  3순위  1편 산업분류코드 조회법
  4순위  7편 산재보험료율
  5순위  6편 직업코드 KSCO/KECO
  6순위  2편 공장찾기·사업성검토
  7순위  5편 경비율 (3~4월에 재수정하면 5월 시즌 유리)

· 2~3일 간격으로 하나씩 올리세요
· 한 번에 몰아 올리면 네이버가 낮게 평가할 수 있습니다

왜 3편이 1순위인가
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

서치어드바이저 데이터를 보면

  "업종코드"  → 노출 447회 (1위)  /  클릭률 0.7% (꼴찌)

노출은 가장 많은데 클릭이 안 됩니다.
사람들이 업종코드 개념을 헷갈려서 뭘 눌러야 할지 모르는 상태예요.

그 혼동을 정확히 풀어주는 글이 3편입니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
발행할 때 지킬 것
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 이미지 2~4장 꼭 넣기
   → 네이버는 이미지 있는 글을 선호합니다
   → ④번 구역에 위치를 표시해뒀습니다

2. 링크는 본문에 1~2회만
   → 도배하면 저품질 판정 위험이 있습니다

3. 소제목은 네이버 에디터 기능으로 꾸미기
   → ✅ 표시된 줄을 소제목으로 지정하면 깔끔합니다

4. 표는 네이버 표 기능으로 다시 만들기
   → 지금은 텍스트로 정리해뒀는데, 표로 바꾸면 가독성이 좋아집니다

5. 글 하단에 시리즈 목차 넣기
   → 이전 글 링크를 걸면 체류시간이 올라갑니다

시리즈 목차 (하단에 넣을 문구)

📚 산업분류코드 시리즈

1편 산업분류코드 조회법 — 물건 이름으로 코드 찾기
2편 공장 찾기·사업성 검토 — 거래처 발굴, 창업 검토
3편 업종코드 vs 산업분류코드 — 5자리? 6자리?
4편 10차→11차 변환 — 137개가 바뀌었습니다
5편 종합소득세 경비율 — 단순경비율·기준경비율
6편 직업코드 조회 — KSCO와 KECO 차이
7편 업종별 산재보험료율 — 5‰~185‰

→ 발행한 글의 링크를 각 줄에 걸어주세요
